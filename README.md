# FreeAI Studio — প্রথম ওয়েব অ্যাপ

এটি মোবাইল ও ডেস্কটপে চলার মতো একটি front-end prototype।

## অন্তর্ভুক্ত
- ড্যাশবোর্ড ও স্টুডিও নেভিগেশন
- AI Director-এর নিয়মভিত্তিক প্রাথমিক পরিকল্পনা
- Video project form
- ডিভাইসের Speech Synthesis দিয়ে টেক্সট পড়া
- Voice Library-তে অনুমতিপ্রাপ্ত ভয়েসের নোট সংরক্ষণ
- Character Library
- Music project form
- Movie & Drama Studio: 10–180+ মিনিটের পরিকল্পনা এবং scene list
- My Projects, localStorage ও JSON export

## গুরুত্বপূর্ণ সীমা
এখনো বাস্তব AI ভিডিও/মিউজিক জেনারেশন, voice cloning, lip-sync, লগইন/ক্লাউড সিঙ্ক বা 120+ মিনিটের রেন্ডারিং যুক্ত নেই। এর জন্য নিরাপদ backend এবং AI provider/model integration প্রয়োজন। ডেটা বর্তমানে এই ব্রাউজারেই থাকে; নিয়মিত JSON export করে ব্যাকআপ রাখুন।

## চালানো
`index.html` ফাইলটি ব্রাউজারে খুলুন। অনলাইনে প্রকাশ করতে GitHub repository-তে ফাইলটি আপলোড করে Settings → Pages → Deploy from a branch → `main` এবং `/ (root)` নির্বাচন করুন।
